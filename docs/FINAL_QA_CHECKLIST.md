## إعادة تشغيل التحقق المحلي

من PowerShell داخل مجلد المشروع:

```powershell
.\scripts\validate_project.ps1
.\scripts\refine_specialization_catalog.ps1
```

يُشغّل `refine_specialization_catalog.ps1` فقط عند الحاجة لإعادة توليد الوسوم والتنظيف النصي؛ راجع `git diff` أو مقارنة الملفات بعد تشغيل سكربتات تعديل البيانات قبل اعتمادها.
