## شرح بسيط لمحرك الـprompt
بدل ما نخزن نص طويل مكرر 229 مرة، فيه قالب تعليمي مشترك داخل `prompt-builder.js`. كل تخصص له سجل منفصل بيوصف طبيعة شغله ومهامه ومخرجاته والمهارات والاحتياطات الخاصة بيه. وقت فتح الصفحة، المتصفح بيجمع القالب مع بيانات الدور ويعرض prompt كامل يقدر المستخدم ينسخه لوحده.

## تحقق مصر ومصادر البحث
حقول التسجيل، توافر مشروع لمصر، وإمكانية الدفع منفصلة. فيه حالات مثبتة جزئيًا من مصادر رسمية، مثل مصر ضمن بلاد المشاركين في Prolific، وقائمة تحويلات Preply البنكية، وطرق سحب Khamsat وMostaql، وإرشادات Outlier. لكن وجود مصر في صفحة مساعدة لا يضمن وجود مهام حاليًا أو صلاحية كل طريقة دفع لكل حساب. معظم إعلانات الوظائف والمنصات تتغير حسب المشروع أو الحساب. حالة `unconfirmed` معناها مافيش دليل رسمي كفاية اتراجع، مش معناها الرفض. 54 أداة من أصل 68 سعرها أو خطتها الحالية غير مؤكدة بالبيانات المنشورة؛ لا تظهر أرقام أسعار مخترعة.

## الاختبارات
تم فحص JSON syntax، تفرد IDs/slugs، صحة روابط التصنيفات والتخصصات، تغطية كل تخصص بإرشاد، وتوليد عينة prompts من أدوار مختلفة. تم فحص syntax لملفات JavaScript. اختبار واجهة متصفح حقيقي، قياس mobile/tablet بصريًا، وconsole لم يتاحوا في جلسة التنفيذ، لذلك لا أعتبرهم ناجحين. تفاصيل الأعداد والنتيجة النهائية في `PHASE_03_VALIDATION.md`.
